# VO2 Max Estimator

Estimate your aerobic fitness level using heart rate data or a 12-minute Cooper run test.

## Features
- Uth-Sørensen formula: VO2max = 15 × (HRmax / HRrest) with auto-calculated max HR option
- Cooper 12-minute run test formula as alternative input method
- Color-coded fitness classification (Poor/Fair/Good/Excellent/Superior) by age and gender
- Improvement tips tailored to your classification
- Bar chart visualizing VO2 Max ranges across fitness levels

## Usage
Select the Heart Rate or Cooper Run tab, fill in your details, and click Estimate. Your result appears in a color-coded card with personalized improvement tips. Refer to the classification table to see how you compare across age groups.
